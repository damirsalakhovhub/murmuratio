See every hidden agent your orchestrator runs.

The leanest way to orchestrate: Claude starts small Codex workers in hidden chats, gives each only what it needs, and replaces them once their context grows. Codex never shows those chats. Murmuratio does: whether a worker is still running, which model it got, how full its context is, and how fast you spend your limits. Made for control freaks and anyone with a touch of OCD.

Why it exists

Claude and Codex are good at different things: design, code, reviews. Some people pay for both and let one of them run the work. That one is the orchestrator.

If Claude is the orchestrator, the cheapest way to work is not to keep long chats open. Claude starts small Codex workers on its own, gives each one only what its task needs, and starts a new one when a worker's context gets too full. Less context, fewer tokens burned.

The catch: Codex does not show these workers. Claude says the work is running, but you cannot see how many workers it started, which model each one got or how full their context is.

Murmuratio shows that. It reads the local Claude Code and Codex files on your Mac and lists every agent by project, with workers under the orchestrator that started them: task, model, status, context use, and your Claude and Codex limits. Nothing leaves your machine.

How it works

Murmuratio is a small web page that runs on your Mac. It reads the files Claude Code and Codex already keep: Claude sessions in ~/.claude/projects, Codex chats in ~/.codex.

Every few seconds it reads them again and matches each Codex worker to the Claude session that started it. Workers appear under their orchestrator, grouped by project.

For every agent it shows the model, what it is doing now, how long it has run and how much of its context window is used. Claude limits come from the Claude Code status line, Codex limits from its local state.

What it does not do

It does not start, stop or steer your agents. It only reads.

It does not send anything anywhere. No account, no telemetry, no cloud. The page is served on 127.0.0.1 and is gone when you stop it.
